# ALORA Travel — Frontend Prototype

Open `index.html` in a browser.

Included:
- Responsive luxury Bali travel/villa homepage.
- Uploaded Bali cinematic video integrated as the hero and destination experience video.
- Click-to-open video modal.
- Six villa cards focused on premium stay/entertainment positioning.
- Responsive mobile layout.
- No backend required for this portfolio prototype.
